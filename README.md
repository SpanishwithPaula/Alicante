# La Copa de los Sonidos — Arthur

Sitio web interactivo de fonética en español, nivel A0-A1.

## Publicación con GitHub Pages

1. Crea un repositorio público en GitHub.
2. Sube `index.html` a la raíz de la rama `main`.
3. Abre Settings → Pages y elige Deploy from a branch, `main`, `/ (root)`.
4. La URL será `https://TU-USUARIO.github.io/NOMBRE-REPOSITORIO/`.

Las fuentes e imágenes externas requieren Internet. Los audios de lectura utilizan las voces disponibles del navegador.
